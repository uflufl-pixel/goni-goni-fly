# 날아라 고니고니 · she's gone~~~y 🦢

노을 지는 갈대밭 위, 흰 **고니(백조)**가 되어 철새 떼(두루미·기러기·철새)와 맞서는 클래식 아케이드 슈팅 게임.
순수 HTML5 Canvas + 바닐라 JavaScript로 만들어 **빌드 도구·의존성이 전혀 없다.**

## ▶ 지금 플레이

**https://uflufl-pixel.github.io/goni-goni-fly/**

PC·모바일 브라우저에서 바로 실행됩니다. (카카오톡 인앱 브라우저 지원)

## 🎮 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | ← → 방향키 | 화면을 드래그 |
| 발사 | 자동발사 | 자동발사 |
| 일시정지 | P | — |
| 시작/재시작 | Enter | 화면 터치 |

## ✨ 특징

- **캡처-구출 & 더블 함선** — 두루미 보스의 견인빔에 잡히면 목숨을 잃지만, 그 보스를 격추해 떨어지는 고니를 받아내면 두 마리로 합체
- **파워업 아이템** — 무기 레벨업(연사·확산탄), 레이저빔, 속사, 보호막, 추가 목숨
- **시간 경과 난이도** — 초반은 완만하고, 5분·10분이 지날수록 급강하·탄막이 거세짐
- **노을 갈대밭 배경** — 그라데이션 하늘 + 흔들리는 갈대밭 + 떠다니는 솜털

## 🛠 로컬에서 실행

`localStorage`(하이스코어 저장)를 쓰므로 `file://`이 아닌 HTTP로 서빙해야 합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000/index.html
```
